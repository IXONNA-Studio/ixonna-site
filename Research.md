## How to swap in the real images

The repo currently ships 1×1 placeholder PNGs at the paths above so the build
stays green. Replace each file in place, keeping the **same filename and path**:

```
vite-project/public/images/ai-portrait.png
vite-project/public/images/ai-workspace.png
```

Recommended export sizes: `ai-portrait.png` ≈ 1440×900, `ai-workspace.png` ≈
1920×824. No code changes are needed after replacing the files.
